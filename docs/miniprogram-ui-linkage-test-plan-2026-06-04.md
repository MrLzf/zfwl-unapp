# 小程序 UI 与联动测试计划（2026-06-04）

## 测试状态

- 测试目标：微信开发者工具中的 `zfwl-unapp` 小程序。
- 测试范围：UI 样式、运行错误、主要页面跳转与表单联动。
- 当前阻塞：Computer Use 客户端文件已恢复，但 Windows native pipe 仍不可用，无法安全自动操作微信开发者工具窗口。
- 后续动作：Computer Use native pipe 恢复后，按本文档清单逐项复测，并把复现结果补充到“问题与优化计划”。

## 待测页面与流程

### 首页

- 验证城市定位展示是否稳定。
- 验证搜索框占位文案是否完整显示。
- 验证“优质教师”“热门需求”卡片是否有文字溢出、价格错位、图片拉伸。
- 验证“查看全部”是否跳转到广场页并带正确角色视角。
- 验证底部 tabbar 高亮、未读角标、发布按钮悬浮位置。

### 老师广场

- 验证标题与当前用户角色是否一致：家长看到“老师广场”，教师看到“需求广场”。
- 验证搜索、学科、距离、排序、筛选入口是否可点击。
- 验证筛选后列表是否刷新，空状态是否清晰。
- 验证教师/需求卡片价格、时间、城市、标签是否对齐。
- 验证点击列表卡片是否进入详情页。

### 发布页

- 验证页面切换是否有加载反馈，避免点击后停留上一页。
- 验证年级选择器打开、滚动、确认、取消流程。
- 验证科目选择器受年级联动限制，切换年级后无效科目会清空。
- 验证“授课方式”切换后，上课地址字段显示/隐藏是否正确。
- 验证预算、手机号、详细要求等校验提示是否准确。
- 验证底部确认按钮不被自定义 tabbar 或安全区遮挡。

### 消息页

- 验证消息摘要加载态、失败态、重试入口。
- 验证“全部已读”后角标是否同步清零。
- 验证各分类入口：审核通知、联系记录、匹配通知、评价通知、积分提醒。
- 验证分类跳转期间是否有点击反馈，避免误以为无响应。
- 验证详情页返回后消息页是否刷新未读数。

### 我的页面

- 验证头像、昵称、角色标签、手机号、认证状态的换行和间距。
- 验证积分、发布、联系记录三个统计入口跳转。
- 验证常用功能入口：收藏、浏览历史、评价、需求/简历管理。
- 验证列表入口：家教档案、选择城市、积分明细、账号资料。
- 验证退出登录按钮是否只在登录后展示。

## 问题与优化计划

### P0：Computer Use native pipe 当前不可用

- 现象：已找到 `computer-use-client.mjs`，但连接时返回 `Computer Use native pipe path is unavailable`，无法执行 Windows 应用自动化。
- 影响：无法完成本轮微信开发者工具真实点击巡检。
- 处理建议：重启 Codex 桌面端或 Computer Use 辅助服务后重新执行本文档测试清单。

### P1：发布页切换和表单提交需重点复测

- 现象：此前巡检曾观察到发布页从 tabbar 进入存在约 2-3 秒延迟。
- 风险：用户点击“发布”后误判为无响应。
- 处理建议：确认是否已有加载态；若没有，增加页面级 loading 或 tabbar 点击即时态。

### P1：发布页底部遮挡需复测

- 现象：此前巡检曾观察到发布页表单底部靠近自定义 tabbar，部分字段和提交按钮可能需要滚动才能完整使用。
- 风险：提交按钮或末尾字段在小屏机型上被遮挡。
- 处理建议：检查 `.publish-shell` 或页面容器底部 padding 是否覆盖 `tabbar + safe-area-inset-bottom`。

### P2：发布页 picker 文案需复测

- 现象：此前巡检曾观察到科目未选择时占位文本疑似被裁切。
- 风险：用户看不清“请选择科目”或“请先选择年级”。
- 处理建议：确认 picker 文本是否单行、省略、垂直居中；小屏机型下优先显示完整短文案。

### P2：消息页跳转反馈需复测

- 现象：此前巡检曾观察到消息分类跳转有短暂延迟。
- 风险：用户连续点击导致重复导航或误判卡顿。
- 处理建议：点击分类后给当前卡片 loading/opacity 反馈，导航完成后恢复。

### P2：我的页顶部信息密度需复测

- 现象：此前巡检曾观察到昵称、身份标签、手机号区域略拥挤。
- 风险：长昵称、长手机号、教师认证状态在小屏上溢出。
- 处理建议：昵称行允许换行，手机号和认证状态支持断行，头像区域保持垂直居中。

### P2：代码质量告警需复测

- 现象：此前开发者工具“代码质量”里有未通过项，指向 `sheep/components/s-uploader/choose-and-upload-file.js`。
- 风险：若仍被识别为未使用文件，会影响质量评分。
- 处理建议：确认所有引用均带 `.js` 扩展，重新扫描代码质量面板。
