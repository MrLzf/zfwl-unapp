# 底部导航发布按钮样式设计

## 目标

优化移动端底部导航视觉效果：五个导航标签文字保持在同一水平线上，中间“发布”图标明显向上突出。

## 范围

- 仅修改 `sheep/components/s-tabbar/s-tabbar.vue` 的样式。
- 不调整路由、底栏数据、图标类名或点击行为。
- 不修改页面内容和其他底栏组件。

## 设计

- 底栏整体高度保持不变，避免额外占用页面空间。
- 普通导航项和中间导航项使用一致的文字位置，确保“首页、广场、发布、消息、我的”在同一水平线上。
- 中间蓝色圆形发布图标相对当前布局向上偏移约 `28rpx`。
- 保留现有白色描边、蓝色背景和阴影，使上浮后的按钮仍有清晰层级。

## 验证

- 检查五个文字标签是否位于同一水平线。
- 检查中间发布图标是否明显高出底栏顶部约 `28rpx`。
- 检查安全区占位高度和其他四个导航项布局是否未受影响。
